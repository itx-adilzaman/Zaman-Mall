# Zaman Mall — Admin Command Center

Standalone admin panel for Zaman Sons Super Mall. Built with React + TypeScript + Vite + Tailwind CSS, fully connected to Supabase.

## Features

- **Dashboard** — Revenue analytics, order charts, category distribution, health snapshot
- **Products** — Add/Edit/Delete products with Cloudinary image/video upload, AI description, variants, country filter
- **Orders** — Full order management with status updates (pending → shipped → delivered → cancelled → returned)
- **Returns** — Approve/reject return requests with customer notifications
- **Messages** — Inbox with admin reply system
- **Users** — View all registered users with order history
- **Banners** — Image/video banner management with live preview
- **App Versions** — Mobile APK version control with critical update flag
- **Categories** — Product categories with Urdu name support

## Setup
